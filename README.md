# yetanotherv2rayforfedora

навайбкодил себе штуку короче чтобы было удобно. если надо пользуйтесь ⚠️ ai slop
Легковесный клиент и демон для **Fedora** (GNOME Shell), который интегрирует **Xray-core** напрямую в системное меню NetworkManager / Quick Settings.

---

## 📌 Что делает и как работает

1. **Интеграция с системным меню GNOME**:
   Сервера из ваших подписок автоматически добавляются в нативное меню быстрых настроек Fedora (в правом верхнем углу, раздел **VPN**). Включать и выключать VPN можно прямо оттуда в один клик.
2. **Прозрачная маршрутизация**:
   Весь трафик системы заворачивается через ядро Xray с использованием TPROXY / TUN-интерфейса `cv2ray0`. DNS настраивается через `systemd-resolved` без утечек.
3. **Поддерживаемые протоколы**:
   Поддерживает **все протоколы ядра Xray**:
   - VLESS (Reality, XHTTP, TCP, gRPC, WebSocket и др.)
   - VMess
   - Trojan
   - Shadowsocks
   - Любые кастомные outbound JSON-конфигурации от вашего провайдера.
4. **Режимы работы**:
   - `tun` — прозрачный системный VPN для всего трафика.
   - `proxy` — только локальные порты SOCKS5 (`127.0.0.1:20808`) и HTTP (`127.0.0.1:20809`).
   - `both` — совмещенный режим (и системный TUN, и порты SOCKS/HTTP).

## 🚀 Установка

Убедитесь, что в системе установлен бинарник `xray` (например, через официальный скрипт Xray-install):
```bash
bash -c "$(curl -L https://github.com/XTLS/Xray-install/raw/main/install-release.sh)" @ install
```

Установка проекта:
```bash
git clone https://github.com/youhacked0/yetanotherv2rayforfedora.git
cd yetanotherv2rayforfedora
sudo ./scripts/install.sh
```

### Что делает скрипт установки:
Скрипт компилирует бинарник и устанавливает команду `v2ray` в `/usr/local/bin/v2ray`. Она становится доступна глобально из любого терминала. Также скрипт регистрирует системную службу systemd и плагин NetworkManager.

Запустите службу демона:
```bash
sudo systemctl enable --now customv2ray
```

## 🖥️ Запуск CLI / TUI меню

Просто наберите в любом терминале:
```bash
v2ray
```

Откроется интерактивное текстовое меню (TUI), где можно стрелками выбирать серверы, нажимать `Enter` для подключения, замерять пинг клавишей `p`, переключать режимы клавишей `m` или смотреть полный JSON-конфиг клавишей `c`.

## 🌐 Управление подписками (HTTPS URL)

Все подписки запрашиваются по HTTPS с кастомным заголовком `User-Agent: Xaked-Prilozhyha` и автоматически обновляются раз в час.

### 1. Добавить подписку по HTTPS URL:
```bash
v2ray sub add "МойСервер" "https://example.com/api/subscription/link"
```
После добавления сервера сразу подгрузятся в память демона и появятся в системном меню VPN NetworkManager.

### 2. Посмотреть список подписок:
```bash
v2ray sub list
```

### 3. Принудительно обновить подписки сейчас:
```bash
v2ray sub update
```

### 4. Удалить подписку:
```bash
v2ray sub remove "МойСервер"
```

## ⚡ Основные консольные команды

- **Открыть меню**: `v2ray`
- **Список серверов и протоколов**:
  ```bash
  v2ray list
  ```
- **Замер пинга (gstatic generate_204)**:
  ```bash
  v2ray ping
  ```
- **Подключение к серверу**:
  ```bash
  v2ray connect "ИмяСервера"
  # или по ID сервера:
  v2ray connect 1a2b3c
  ```
- **Отключение**:
  ```bash
  v2ray disconnect
  ```
- **Текущий статус**:
  ```bash
  v2ray status
  ```
- **Смена режима работы**:
  ```bash
  v2ray mode tun      # системный VPN
  v2ray mode proxy    # только локальные прокси
  v2ray mode both     # оба сразу
  ```
- **Просмотр логов в реальном времени**:
  ```bash
  v2ray log
  ```
- **Синхронизация профилей с NetworkManager**:
  ```bash
  v2ray sync
  ```
