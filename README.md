# yetanotherv2rayforfedora

Легковесный клиент и нативный плагин NetworkManager для **Fedora (GNOME Shell)**, который интегрирует серверы Xray прямо в системное меню быстрых настроек (Quick Settings).

---

## 📌 Что делает

- **Интеграция в системный трей Fedora**: серверы из ваших подписок отображаются прямо в меню **VPN** правого верхнего угла GNOME. Включение и смена сервера происходят в один клик без сторонних GUI-окон.
- **Минимум ресурсов**: фоновый демон на Go потребляет **<25 МБ RAM** (в отличие от Electron/Qt клиентов на 500+ МБ).
- **Автоматизация подписок**: забирает и обновляет подписки каждый час в фоновом режиме.
- **Управление на выбор**:
  - Системный переключатель в GNOME Quick Settings
  - Интерактивный терминальный интерфейс (**TUI**) с пингом и просмотром конфигов
  - Консольные команды (**CLI**)

---

## ⚙️ Как работает

1. **NetworkManager D-Bus плагин**: регистрирует соединения в системе и связывает системный переключатель VPN с демоном.
2. **Фоновый демон (`customv2ray`)**: работает через `systemd`, управляет процессом `xray-core`, обновляет подписки и генерирует рабочие конфигурации.
3. **Маршрутизация (TUN / TPROXY)**:
   - Создает виртуальный интерфейс `cv2ray0`.
   - Прозрачно заворачивает системный трафик в Xray без утечек DNS (с интеграцией в `systemd-resolved` / `resolvectl`).
   - Дополнительно поднимает локальные порты SOCKS5 (`:20808`) и HTTP (`:20809`).
4. **Консоль и интерфейс**: утилита `v2ray` общается с демоном через локальный Unix-сокет (`/run/customv2ray/daemon.sock`).

---

## 🌐 Поддерживаемые протоколы

Клиент использует официальное ядро **Xray-core**, поэтому поддерживаются **абсолютно все протоколы и транспорты ядра Xray**:

- **Протоколы**: VLESS, VMess, Trojan, Shadowsocks (включая 2022 / SIP002), WireGuard, Dokodemo-door, Socks, HTTP.
- **Транспорты**: TCP, XHTTP, HTTP/2, gRPC, WebSocket, QUIC, mKCP.
- **Безопасность и маскировка**: Reality, TLS, uTLS, XTLS (Vision).
- **Форматы подписок**: стандартные ссылки (`vless://`, `ss://`, `trojan://`), base64-списки, а также сырые JSON-конфигурации от сервера подписки (полные конфиги или списки outbounds).

## 🚀 Быстрый старт

### 1. Установка

```bash
git clone https://github.com/notxaked/yetanotherv2rayforfedora.git
cd yetanotherv2rayforfedora
sudo ./scripts/install.sh
```

*(Требуются установленный Go 1.21+ и бинарник `xray` в системе).*

### 2. Запуск сервиса

```bash
sudo systemctl enable --now customv2ray
```

### 3. Добавление подписки

```bash
v2ray sub add "МойСервер" "https://example.com/subscription/url"
```

После добавления подписки серверы сразу появятся в системном меню VPN Fedora, а также в TUI/CLI:

```bash
# Открыть терминальный интерфейс:
v2ray

# Или подключиться через консоль:
v2ray connect "ИмяСервера"

# Проверить статус или замерить пинг:
v2ray status
v2ray ping
```
